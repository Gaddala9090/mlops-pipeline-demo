# MLOps Pipeline Demo

An end-to-end machine learning pipeline showing how a model goes from raw data to a monitored, production deployment — not just a notebook that stops at "here's my accuracy."

## Problem
Most ML projects stop at a trained model in a notebook. This project shows the full lifecycle: training, experiment tracking, containerization, deployment, and monitoring — the parts that actually matter in production.
